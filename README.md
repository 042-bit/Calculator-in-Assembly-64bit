# Calculator-in-Assembly-64bit

> [!Warning]
> Calculator can calc only numbers between 0x00 to 0xFFF ( 4095 )


> [!Note]
> Below are the operators that can be used in the second argument.


|operators | Function |
| ---      | ---      |
|    +     |   ADD    |
|    -     |   SUB    |
|    *     |   MUL    |
|    /     |  DIV     |
